4013. Count Subarrays With Even Odd Ratio II

You are given an integer array `nums` and two integers `a` and `b`.

For a subarray, let:

* `x` be the number of even elements.
* `y` be the number of odd elements.

The ratio of even to odd elements in a subarray is defined as `x / y`, where ratios are compared by their exact rational values.

A subarray is considered **valid** if:

* `y > 0`, and
* `x / y <= a / b`.

Return the number of valid subarrays in `nums`.

 

**Example 1:**
```
Input: nums = [1,2,1,2], a = 3, b = 2

Output: 7

Explanation:

The following are the valid subarrays:

Subarray	Values	Even Count	Odd Count	Ratio
nums[0..0]	[1]	0	1	0 / 1
nums[0..1]	[1, 2]	1	1	1 / 1
nums[0..2]	[1, 2, 1]	1	2	1 / 2
nums[0..3]	[1, 2, 1, 2]	2	2	2 / 2
nums[1..2]	[2, 1]	1	1	1 / 1
nums[2..2]	[1]	0	1	0 / 1
nums[2..3]	[1, 2]	1	1	1 / 1
Thus, the number of valid subarrays is 7.
```

**Example 2:**
```
Input: nums = [2,2,1], a = 2, b = 1

Output: 3

Explanation:

The following are the valid subarrays:

Subarray	Values	Even Count	Odd Count	Ratio
nums[0..2]	[2, 2, 1]	2	1	2 / 1
nums[1..2]	[2, 1]	1	1	1 / 1
nums[2..2]	[1]	0	1	0 / 1
Thus, the number of valid subarrays is 3.
```

**Example 3:**
```
Input: nums = [2,2,2], a = 1, b = 1

Output: 0

Explanation:

Every subarray contains 0 odd numbers, so no subarray is valid.
```
 

**Constraints:**

* `1 <= nums.length <= 10^5`
`1 <= nums[i] <= 10^9`
`1 <= a, b <= 10^9`

**Solution 1: (Prefix Sum, merge sort, count inversion)**

__Intuition__
A subarray is valid if the ratio of the number of even elements to the number of odd elements is less than or equal to a / b.

Instead of comparing two fractions directly, we use cross multiplication:

even × b <= odd × a

Rearranging this condition gives:

even × b - odd × a <= 0

Now, we transform the array by assigning:

+b for every even element.
-a for every odd element.

With this transformation, the sum of any subarray becomes:

(number of even elements × b) - (number of odd elements × a)

Therefore, a subarray is valid if its transformed sum is less than or equal to 0.

To efficiently calculate subarray sums, we build a prefix sum array. If pref[i] represents the prefix sum up to index i, then the transformed sum of a subarray from l to r is:

pref[r + 1] - pref[l]

The condition becomes:

pref[r + 1] <= pref[l]

So, the problem is reduced to counting the number of pairs (i, j) such that i < j and pref[j] <= pref[i].

__Approach__
First, convert the original array into a transformed array by replacing every even element with +b and every odd element with -a. Then, compute the prefix sum array of these transformed values.

To count all valid pairs efficiently, use a modified Merge Sort on the prefix sum array. During the merge step, both halves are already sorted. For every prefix sum in the left half, count how many prefix sums in the right half satisfy pref[right] <= pref[left] using a two-pointer technique. Since the halves are sorted, this counting is done in linear time during each merge.

After counting, merge the two halves as in the standard Merge Sort algorithm. The total count accumulated over all merge steps is the required answer.

__Complexity__
Time complexity:

Building the transformed prefix sum array: O(n)

Modified Merge Sort: O(n log n)

O(nlogn)

Space complexity:

Prefix sum array: O(n)

Temporary array used during merge: O(n)

O(n)

y: odd

-> prefix(bx - ay)

->       i   <     j

class Solution {
    long long solve(vector<long long>& pref, int l, int r) {
        if(l >= r) return 0;
        int mid = l + (r - l) / 2;
        long long cnt = solve(pref, l, mid) + solve(pref, mid + 1, r);
        int j = mid + 1;
        for(int i = l; i <= mid; i++) {
            while(j <= r && pref[j] <= pref[i]) {
                j++;
            }
            cnt += (j - (mid + 1));
        }
        vector<long long> temp;
        int i = l;
        j = mid + 1;
        while(i <= mid && j <= r) {
            if(pref[i] <= pref[j]) {
                temp.push_back(pref[i]);
                i++;
            }
            else {
                temp.push_back(pref[j]);
                j++;
            }
        }
        while(i <= mid) {
            temp.push_back(pref[i]);
            i++;
        }
        while(j <= r) {
            temp.push_back(pref[j]);
            j++;
        }
        for(int k = 0; k < temp.size(); k++) {
            pref[l + k] = temp[k];
        }
        return cnt;
    }
public:
    long long countRatioSubarrays(vector<int>& nums, int a, int b) {
        long long ans = 0;
        int n = nums.size();
        vector<long long> pref(n + 1, 0);
        for(int i = 0; i < n; i++) {
            if(nums[i] % 2 == 0) pref[i + 1] = pref[i] + b;
            else pref[i + 1] = pref[i] - a;
        }
        ans = solve(pref, 0, n);
        return ans;
    }
};
