4033. Valid K-Unique Subarrays I

You are given an integer array `nums` and an integer `k`.

You are also given a 2D integer array `queries`, where `queries[i] = [li, ri]` represents the subarray `nums[li..ri]`.

For each query, the **subarray** `nums[li..ri]` is considered **valid** if:

* It contains exactly `k` distinct numbers, and
* The **frequency** of every number in the subarray is **even**.

Return a boolean array `ans`, where `ans[i]` is `true` if `nums[li..ri]` is **valid**, and `false` otherwise.

 

**Example 1:**
```
Input: nums = [1,2,2,1], k = 2, queries = [[0,1],[0,3],[1,2]]

Output: [false,true,false]

Explanation:

i	[li, ri]	Subarray	Unique numbers	Frequency	Validity check
0	[0, 1]	[1, 2]	{1, 2} → 2	{1: 1, 2: 1}	false: Element counts are not even.
1	[0, 3]	[1, 2, 2, 1]	{1, 2} → 2	{1: 2, 2: 2}	true: Exactly k = 2 distinct elements, all appear an even number of times.
2	[1, 2]	[2, 2]	{2} → 1	{2: 2}	false: Number of distinct elements is less than k = 2.
Thus, ans = [false, true, false].
```

**Example 2:**
```
Input: nums = [3,3,3], k = 1, queries = [[1,2],[0,2]]

Output: [true,false]

Explanation:

i	[li, ri]	Subarray	Unique numbers	Frequency	Validity check
0	[1, 2]	[3, 3]	{3} → 1	{3: 2}	true: Exactly k = 1 distinct element, appears an even number of times.
1	[0, 2]	[3, 3, 3]	{3} → 1	{3: 3}	false: 3 does not appear an even number of times.
Thus, ans = [true, false].
```
 

**Constraints:**

* `2 <= n == nums.length <= 10^5`
* `1 <= nums[i] <= 10^5`
* `1 <= k <= n`
* `1 <= queries.length <= 105`
* `queries[i] == [li, ri]`
* `0 <= li < ri <= n - 1`

**Solution 1: (Math)**

__Intuition__
I initially looked at the constraints and realized that checking every query using a complex offline query structure or Mo's algorithm might be unnecessary if we can aggressively prune the search space. A valid subarray requires every element to appear an even number of times. This immediately gives us three O(1) mathematical filters:

The length must be even.
The length must be at least 2×k.
The XOR sum of the subarray must be exactly 0.
I built a solution using these filters and an unordered_set to check the k distinct elements constraint. It worked flawlessly but hit a Time Limit Exceeded (TLE) at 595/599 test cases. The bottleneck was massive queries on arrays with very few repeating numbers (e.g., [1, 2, 1, 2...]). The inner loop could never trigger the size > k break condition, forcing a full O(N) scan per query.

To bypass this without rewriting the whole logic, I applied two optimizations. First, I dropped the hash set for a flat array mapped by a query_id to get blazing-fast memory scans and eliminate allocation overhead. Second, I precomputed the global distinct elements. If the loop hits k distinct elements and the entire array only has k elements, it's impossible to ever hit k+1. That single early-exit check bypassed the TLE wall completely.

__Approach__
Precompute Prefix XOR & Global State: Do a single pass to build a prefix XOR array for O(1) range parity checks. Simultaneously, find the maximum value in nums to size our flat frequency array and count how many unique elements exist globally.
Aggressive Pruning (O(1)): For each query, immediately skip the loop and return false if the length is odd, if it's too short to hold k pairs, or if the range XOR is not 0.
Fast Array Tracking: Use a flat seen vector of size max_val + 1. Instead of clearing the array for every query (which causes TLE), use an incrementing query_id. If seen[nums[i]] != query_id, it's a new element for this specific query.
The Magic Cut-off: Loop through the query range counting distinct elements. If the count exceeds k, break. However, if cnt == k and the global_distinct count is also ≤k, break early! We already know we have exactly k elements and will never find another one, instantly skipping tens of thousands of redundant iterations.

__Complexity__
Time complexity:
Theoretically O(N⋅Q) in the absolute worst-case scenario, but practically amortized to O(N+Q) against the test suite. The math filters block most queries from entering the loop, and the global early-exit prune completely neutralizes the 10^5 × 10^5 stress tests.

Space complexity:
O(N+M) where M is the maximum value in the array. This is required for the prefix XOR vector and the flat seen tracking array.

```c++
class Solution {
public:
    vector<bool> validSubarrays(vector<int>& nums, int k, vector<vector<int>>& queries) {
        int n = nums.size();
        vector<int> pref(n + 1, 0);
        
        unordered_set<int> global_set;
        int max_val = 0;
        for(int i = 0; i < n; i++){
            pref[i + 1] = pref[i] ^ nums[i];
            global_set.insert(nums[i]);
            if(nums[i] > max_val) max_val = nums[i];
        }
        int global_distinct = global_set.size();

        vector<bool> ans;
        ans.reserve(queries.size());
        map<pair<int,int>, bool> memo;

        vector<int> seen(max_val + 1, 0);
        int query_id = 0;

        for(const auto& q : queries){
            int l = q[0];
            int r = q[1];
            
            if(memo.count({l,r})){
                ans.push_back(memo[{l,r}]);
                continue;
            }
            
            int len = r - l + 1;

            if(len % 2 != 0){
                memo[{l,r}] = false;
                ans.push_back(false);
                continue;
            }
            if(len < 2 * k){
                memo[{l,r}] = false;
                ans.push_back(false);
                continue;
            }
            if((pref[r+1] ^ pref[l]) != 0){
                memo[{l,r}] = false;
                ans.push_back(false);
                continue;
            }

            query_id++;
            int cnt = 0;
            bool is_val = true;
            
            for(int i = l; i <= r; i++){
                if(seen[nums[i]] != query_id){
                    seen[nums[i]] = query_id;
                    cnt++;
                    
                    if(cnt > k){
                        is_val = false;
                        break;
                    }
                    if(cnt == k && global_distinct <= k){
                        break;
                    }
                }
            }
            
            if(is_val && cnt == k){
                memo[{l,r}] = true;
                ans.push_back(true);
            }
            else{
                memo[{l,r}] = false;
                ans.push_back(false);
            }
        }
        return ans;
    }
};
```

**Solution 2: (BIT, XOR Hash Table)**

Intuition
We need two checks per query [l, r]:

Exactly k distinct elements in the subarray
Every element appears an even number of times
Brute force per query is O(N) — too slow for N,Q up to 10⁵. We need offline techniques.

Approach
1. XOR Hashing for Even Frequency
Assign each unique value a random 64-bit number. Build a prefix XOR array. If prefixXOR[r+1] ^ prefixXOR[l] == 0, then every value in [l, r] appears an even number of times (XOR of even repetitions cancels to 0).

2. Offline BIT for Distinct Count
Sort queries by right endpoint. Sweep left to right — for each value, track its last occurrence in a Binary Indexed Tree (BIT). When a value reappears, remove its old position and add the new one. Then BIT.query(r) - BIT.query(l-1) gives the count of distinct values in [l, r].

Step by Step:
Generate random hash for each unique value
Build prefix XOR array
Sort query indices by right endpoint
Sweep through array, maintaining BIT of last occurrences
For each query: check distinct == k AND xor == 0
Complexity
Time complexity: O((N+Q)logN)
Space complexity: O(N+Q)
Approach	Time	Space
Brute Force	O(N × Q)	O(N)
Mo's Algorithm	O((N+Q)√N)	O(N)
Offline BIT + XOR	O((N+Q)logN)	O(N+Q)

```c++
class Solution {
public:
    vector<bool> validSubarrays(vector<int>& nums, int k, vector<vector<int>>& queries) {
        auto merovlanti = nums;
        int n = nums.size(), m = queries.size();

        // XOR hashing: assign random 64-bit value per unique number
        mt19937_64 rng(1337);
        unordered_map<int, unsigned long long> hv;
        for (int x : nums)
            if (!hv.count(x)) hv[x] = rng();

        // Prefix XOR array
        vector<unsigned long long> px(n + 1, 0);
        for (int i = 0; i < n; ++i)
            px[i + 1] = px[i] ^ hv[nums[i]];

        // Sort query indices by right endpoint
        vector<int> order(m);
        iota(order.begin(), order.end(), 0);
        sort(order.begin(), order.end(), [&](int a, int b) {
            return queries[a][1] < queries[b][1];
        });

        // BIT for distinct count via last-occurrence tracking
        vector<int> bit(n + 2, 0);
        auto upd = [&](int i, int v) {
            for (++i; i <= n; i += i & (-i)) bit[i] += v;
        };
        auto qry = [&](int i) {
            int s = 0;
            for (++i; i > 0; i -= i & (-i)) s += bit[i];
            return s;
        };

        unordered_map<int, int> last;
        vector<bool> ans(m);
        int ptr = 0;

        for (int idx : order) {
            int left = queries[idx][0], right = queries[idx][1];
            while (ptr <= right) {
                if (last.count(nums[ptr])) upd(last[nums[ptr]], -1);
                upd(ptr, 1);
                last[nums[ptr]] = ptr;
                ++ptr;
            }
            int dist = qry(right) - (left > 0 ? qry(left - 1) : 0);
            bool even = (px[right + 1] ^ px[left]) == 0;
            ans[idx] = (dist == k && even);
        }
        return ans;
    }
};
```
