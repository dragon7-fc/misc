4023. Elevator Requests II

You are given an integer `n` denoting the number of floors in a building, where the floors are numbered from 0 to `n - 1`.

You are also given an integer `start`, representing the floor where the elevator begins, and an integer array `requests`, where `requests[i]` is a floor that the elevator is requested to reach. All floors in requests are **distinct**.

At time 0, the elevator is on floor `start`, and all requests are made **simultaneously**.

During each second before all requests are fulfilled, the elevator moves exactly one floor, either up or down. A request is fulfilled instantly when the elevator reaches its requested floor. If `start` appears in `requests`, that request is fulfilled at time 0.

For each second that a request remains unfulfilled, you receive 1 penalty. Equivalently, a request fulfilled at time `t` contributes `t` to the total penalty.

Return the **minimum** total penalty required to fulfill all requests.

 

**Example 1:**
```
Input: n = 6, start = 4, requests = [1,5]

Output: 6

Explanation:

Move from floor 4 (start) to floor 5 in 1 second. Penalty for floor 5 is 1.
Move from floor 5 to floor 1 in 4 seconds. Penalty for floor 1 is 5.
Thus, the total penalty is 1 + 5 = 6.
```

**Example 2:**
```
Input: n = 8, start = 3, requests = [3,7,1]

Output: 10

Explanation:

Floor 3 (start) is fulfilled instantly. Penalty for floor 3 is 0.
Move from floor 3 to floor 1 in 2 seconds. Penalty for floor 1 is 2.
Move from floor 1 to floor 7 in 6 seconds. Penalty for floor 7 is 8.
Thus, the total penalty is 0 + 2 + 8 = 10.
```

**Example 3:**
```
Input: n = 10, start = 5, requests = [0,2,9]

Output: 22

Explanation:

Move from floor 5 (start) to floor 2 in 3 seconds. Penalty for floor 2 is 3.
Move from floor 2 to floor 0 in 2 seconds. Penalty for floor 0 is 5.
Move from floor 0 to floor 9 in 9 seconds. Penalty for floor 9 is 14.
Thus, the total penalty is 3 + 5 + 14 = 22.
```
 

**Constraints:**

* `1 <= n <= 10^9`
* `1 <= requests.length <= 1500`
* `0 <= start, requests[i] <= n - 1`
* All values in `requests` are **distinct**.

# Submissions
---
**Solution 1: (DP Bottom-Up, Interval DP + Cost Distribution)**

__Intuition__
There are two massive insights required to solve this efficiently:

Contiguous Visiting: Since we want to minimize travel time, the set of fulfilled requests will always form a contiguous range [i, j] when the requests are sorted. If the elevator is moving right, it makes no sense to skip a requested floor and come back for it later.
Cost Distribution (The Magic Trick): The penalty for a request is the time it is fulfilled. Instead of tracking the absolute elapsed time T in our DP state (which would cause an Out-Of-Memory error since T can be huge), we can calculate the penalty dynamically!
Whenever the elevator moves a distance of D, every single unfulfilled request is delayed by D seconds. Therefore, a single move of distance D instantly adds D×(number of remaining unfulfilled requests) to our total penalty.

__Approach__
Preparation:
Check if start is already in the requests array. If not, add it.
Sort the requests array. The elevator will now always cover a sliding window [i, j] of this sorted array.
Find the starting index sidx of the start floor.
State Definition:
Let dp[i][j][0] be the minimum penalty to fulfill all requests in the range [i, j], with the elevator currently parked at the left end (requests[i]).
Let dp[i][j][1] be the minimum penalty to fulfill the range [i, j], with the elevator currently parked at the right end (requests[j]).
Initialize all states to infinity (1e18), except dp[sidx][sidx][0] = 0 and dp[sidx][sidx][1] = 0.
DP Transitions (Expanding the Interval):
We iterate over the length of the fulfilled interval len from 1 to M−1.
For a current interval [i, j], the number of remaining unfulfilled requests is rem = m - len.
Expand Left (to i - 1): We can reach i - 1 either from the current left (i) or the current right (j).
From left: Cost = dp[i][j][0] + distance(requests[i], requests[i-1]) * rem
From right: Cost = dp[i][j][1] + distance(requests[j], requests[i-1]) * rem
Expand Right (to j + 1): We can reach j + 1 either from the current left (i) or the current right (j).
From left: Cost = dp[i][j][0] + distance(requests[j+1], requests[i]) * rem
From right: Cost = dp[i][j][1] + distance(requests[j+1], requests[j]) * rem
Result: The answer is the minimum of dp[0][m-1][0] and dp[0][m-1][1], which represents fulfilling all requests from index 0 to M−1 and ending up on either side.

__Complexity__
Time Complexity: O(M^2).
Space Complexity: O(M^2).

```
Runtime: 271 ms, Beats 37.50%
Memory: 289.38 MB, Beats 62.50%
```
```c++
class Solution {
public:
    long long elevatorRequests(int n, int start, vector<int>& requests) {
        constexpr long long INF = 1e18;
        
        bool st = false;
        for(int r : requests) {
            if(r == start) {
                st = true;
                break;
            }
        }
        if(!st) requests.push_back(start);

        sort(requests.begin(), requests.end());
        int m = requests.size();
        int sidx = lower_bound(requests.begin(), requests.end(), start) - requests.begin();

        // dp[i][j][0] = min penalty for range [i, j] ending at the left (i)
        // dp[i][j][1] = min penalty for range [i, j] ending at the right (j)
        vector<vector<array<long long, 2>>> dp(m, vector<array<long long, 2>> (m, {INF, INF}));
        
        // Base case: Starting at 'start' costs 0 time
        dp[sidx][sidx][0] = 0;
        dp[sidx][sidx][1] = 0;

        for(int len = 1; len < m; ++len) {
            for(int i = 0; i + len - 1 < m; ++i) {
                int j = i + len - 1;
                
                // Number of requests still waiting to be fulfilled
                int rem = m - len; 
                
                // Expand Left: Move to i - 1
                if(i > 0) {
                    // From left (i)
                    dp[i - 1][j][0] = min(dp[i - 1][j][0], dp[i][j][0] + 1LL * (requests[i] - requests[i - 1]) * rem);
                    // From right (j)
                    dp[i - 1][j][0] = min(dp[i - 1][j][0], dp[i][j][1] + 1LL * (requests[j] - requests[i - 1]) * rem);
                }
                
                // Expand Right: Move to j + 1
                if(j < m - 1) {
                    // From left (i)
                    dp[i][j + 1][1] = min(dp[i][j + 1][1], dp[i][j][0] + 1LL * (requests[j + 1] - requests[i]) * rem);
                    // From right (j)
                    dp[i][j + 1][1] = min(dp[i][j + 1][1], dp[i][j][1] + 1LL * (requests[j + 1] - requests[j]) * rem);
                }
            }
        }

        return min(dp[0][m - 1][0], dp[0][m - 1][1]);
    }
};
```
