4041. Minimum Operations to Form Subset Sum II

You are given an integer array `nums` and an integer `sum`.

In one operation, choose an element with current value `x` and replace it with either `2 * x` or `floor(x / 2)`.

For each element, **multiplication** and **division** operations may be performed in any order.

Return the **minimum** number of operations needed so that some **subset** of the resulting array has a sum exactly equal to `sum`. If it is impossible, return `-1`.

The `floor()` function returns the integer part of the division.

 

**Example 1:**
```
Input: nums = [10,2], sum = 13

Output: 3

Explanation:

Divide nums[0] = 10 once: 10 → 5, costing 1 operation.
Multiply nums[1] = 2 twice: 2 → 4 → 8, costing 2 operations.
After these operations, nums = [5, 8]. The subset {5, 8} sums to 13 using 3 operations in total.
```

**Example 2:**
```
Input: nums = [6,3], sum = 8

Output: 2

Explanation:

Turn nums[1] = 3 into 2 using 2 operations:
Divide nums[1] to get 1.
Multiply nums[1] = 1 to get 2.
After these operations, nums = [6, 2]. The subset {6, 2} sums to 8 using 2 operations in total.
```

**Example 3:**
```
Input: nums = [2,2], sum = 7

Output: -1

Explanation:

No sequence of operations lets a subset of nums sum to 7, so the answer is -1.
```

**Constraints:**

* `1 <= nums.length <= 100`
* `1 <= nums[i] <= 500`
* `1 <= sum <= 5000`

# Submissions
---
**Solution 1: (DP Bottom-Up)**

__Intuition__
Same core idea as Part 1: every number in nums can be doubled or halved, each operation costing 1, and we want to pick a transformed value from each number (or skip it) so that a subset of these transformed values sums exactly to sum, using the fewest total operations. This version tightens the generation of reachable values by combining the "halve first, then double back up" traversal into a single nested loop, and stops the doubling early once a value exceeds sum / 2 (since doubling further would only overshoot sum).

__Approach__
DP definition: dp[s] = minimum operations to make some subset of the numbers processed so far sum to exactly s. Start with dp[0] = 0 and everything else at infinity (INF = 1e18).
Per-number reachable values: For each number x:
Walk curr down from x to 0 via repeated integer halving, counting down steps.
At each halving level, walk val up from curr via repeated doubling (counting up steps), stopping once val > sum or once val > sum / 2 (to avoid an overshoot on the next doubling).
For each such val, record the minimum total operations (down + up) needed to reach it in cost[val], and track it once in options the first time it's discovered.
Merge into the DP: For each achievable sum s in the current dp (skipping infinities) and each (value, operations) pair in options, update next[s + value] = min(next[s + value], dp[s] + operations), as long as s + value <= sum.
Replace dp with next after processing each number, ensuring each number contributes at most one transformed value to any given sum.
After processing all numbers, dp[sum] is the answer; if still infinity, return -1.

__Complexity__
Time complexity:
O(n⋅log(sum)⋅sum)
For each of the n numbers, halving down takes O(log(x)) steps, and at each level doubling back up takes O(log(sum)) steps in the worst case, giving O(log(sum)) reachable values per number; merging these into the DP over all sum partial sums gives the stated bound.

Space complexity:
O(sum)
For the dp, next, and cost arrays (each of size sum + 1).

```
Runtime: 521 ms, Beats 83.49%
Memory: 130.35 MB, Beats 9.28%
```
```c++
class Solution {
public:
    int minOperations(vector<int>& nums, int sum) {
        long long INF = 1e18;
        vector<long long> dp(sum + 1, INF);
        dp[0] = 0;
        for (long long x : nums) {
            vector<long long> cost(sum + 1, INF);

            vector<pair<int, int>> options;

            long long curr = x;
            int down = 0;
            while (curr > 0) {

                long long val = curr;
                int up = 0;
                while (val <= sum) {

                    if (cost[val] == INF) {
                        options.push_back({(int)val, down + up});
                    }

                    cost[val] = min(
                        cost[val],
                        (long long)down + up
                    );

                    if (val > sum / 2)
                        break;

                    val *= 2;
                    up++;
                }

                curr /= 2;
                down++;
            }
            vector<long long> next = dp;

            for (int s = 0; s <= sum; s++) {

                if (dp[s] == INF)
                    continue;

                for (auto [value, operations] : options) {

                    if (s + value > sum)
                        continue;

                    next[s + value] = min(
                        next[s + value],
                        dp[s] + operations
                    );
                }
            }

            dp = move(next);
        }
        if(dp[sum] == INF){
            return -1;
        }
        return dp[sum];
    }
};
```
